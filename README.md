## 📖 প্রজেক্ট সম্পর্কে (About The Project)

বাংলাদেশে নিত্যপ্রয়োজনীয় পণ্য যেমন—চাল, ডাল, তেল, সবজি, মাছ, মাংস ও মসলার দাম প্রতিনিয়ত ওঠানামা করে। সাধারণ ক্রেতা ও ভোক্তাদের সুবিধার্থে আমি এই **"বাজার দর"** ওয়েব অ্যাপ্লিকেশনটি তৈরি করেছি। 

এখানে ব্যবহারকারীরা খুব সহজেই আজকের বাজার দর, গতকালের তুলনায় দামের পরিবর্তন (বেড়েছে নাকি কমেছে), বিভিন্ন পাইকারি ও খুচরা বাজারের দামের তারতম্য দেখতে পারবেন। অ্যাপ্লিকেশনটিতে আধুনিক **Next.js 16 App Router**, **TypeScript**, **Tailwind CSS** এবং নিরাপদ অথেনটিকেশনের জন্য **BetterAuth** ও **MongoDB Atlas** ব্যবহার করা হয়েছে।

## ✨ প্রধান ৫টি উল্লেখযোগ্য বৈশিষ্ট্য (Key Features)

### ১. 🔄 ডাইনামিক প্রাইস টিকার ও ক্যাটাগরি ব্রাউজিং
- ওয়েবসাইটের ব্যানারের ঠিক উপরে একটি মসৃণ **ইনফিনিট স্ক্রলিং প্রাইস টিকার** যুক্ত করেছি, যেখানে প্রতিটি পণ্যের আইকন, নাম, আজকের দাম এবং বৃদ্ধির/হ্রাসের শতকরা হার সরাসরি স্ক্রল হতে থাকে।
- চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলা—এই ৮টি ক্যাটাগরির চিপসে ক্লিক করে এক ক্লিকেই নির্দিষ্ট ক্যাটাগরির পণ্যসমূহ ফিল্টার করা যায়।

### ২. 📈 আজকের দর ওঠানামা বিশ্লেষণ (Risers & Fallers)
- **আজ দাম বেড়েছে ▲:** বাজারে যে শীর্ষ ৬টি পণ্যের দাম গতকালের চেয়ে বৃদ্ধি পেয়েছে, তা স্বয়ংক্রিয়ভাবে ক্যালকুলেট করে সবুজ ব্যাজ সহ দেখানো হয়।
- **আজ দাম কমেছে ▼:** যে শীর্ষ ৬টি পণ্যের দাম হ্রাস পেয়েছে, তা লাল ব্যাজ সহ স্পষ্টভাবে তুলে ধরা হয়েছে।

### ৩. ⚖️ সংখ্যাভিত্তিক বাংলা সর্টিং (Challenge C1)
- প্রজেক্টে বাংলা সংখ্যা থাকা সত্ত্বেও অভ্যন্তরীণভাবে নিখুঁত সংখ্যাগত মানের (Numeric Value) ভিত্তিতে সর্টিং সিস্টেম তৈরি করেছি।
- ব্যবহারকারীরা ৩টি মোডে পণ্য সাজাতে পারেন:
  - `ডিফল্ট`
  - `দাম: কম থেকে বেশি`
  - `দাম: বেশি থেকে কম`
- ক্যাটাগরি পেজ এবং হোম পেজের সব পণ্য সেকশনে রিয়েল-টাইম সার্চের পাশাপাশি এই সর্টিং সম্পূর্ণ কার্যকর।

### ৪. 🔒 সুরক্ষিত পণ্যের বিস্তারিত পৃষ্ঠা ও ১২-বাজারের তুলনা (Protected Product Details)
- পণ্যের বিস্তারিত রুট (`/product/[slug]`) একটি সম্পূর্ণ **সুরক্ষিত (Protected) রুট**।
- সাইন ইন ছাড়া কেউ পণ্যের ডিটেইলস দেখতে চাইলে স্বয়ংক্রিয়ভাবে টোস্ট মেসেজ সহ লগইন পেজে রিডাইরেক্ট করা হয় এবং লগইন শেষে পুনরায় পূর্বের পেজে ফিরিয়ে আনা হয়।
- বিস্তারিত পেজে ৩টি প্রাইস সামারি কার্ড (সর্বনিম্ন দর, সর্বোচ্চ দর, গড় দর) এবং কারওয়ান বাজার, নিউ মার্কেট, খাতুনগঞ্জসহ বাংলাদেশের ১২টি পাইকারি ও খুচরা বাজারের তুলনামূলক টেবিল প্রদর্শন করা হয়েছে।

### ৫. 👤 নিরাপদ BetterAuth অথেনটিকেশন ও প্রোফাইল আপডেট (Challenge C3)
- **মাল্টি-মেথড লগইন:** ইমেইল/পাসওয়ার্ডের পাশাপাশি Google ও GitHub সোশ্যাল লগইন সুবিধা।
- **তথ্য হালনাগাদ (C3):** প্রোফাইল পেজে গিয়ে আলাদা রুটে (`/profile/update`) নাম পরিবর্তনের ফর্ম দেওয়া হয়েছে, যা BetterAuth-এর মাধ্যমে সরাসরি ক্লাউড ডাটাবেজে ইউজারের নাম আপডেট করে দেয়।
- সকল ফর্ম ও ভ্যালিডেশনে বাংলা ভাষায় স্পষ্ট টোস্ট অ্যালার্ট ও নোটিফিকেশন যুক্ত করেছি।

## 💻 লোকাল মেশিনে যেভাবে রান করবেন (Getting Started)

প্রজেক্টটি আপনার কম্পিউটারে রান করতে নিচের ধাপগুলো অনুসরণ করুন:

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/princeinctg/bazar-dor.git
cd bazar-dor
```

### ২. ডিপেন্ডেন্সি ইনস্টল করুন
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ করুন
প্রজেক্টের রুট ডিরেক্টরিতে একটি `.env.local` ফাইল তৈরি করুন এবং নিচের মতো ভ্যারিয়েবল দিন:
```env
BETTER_AUTH_SECRET=your-32-character-secret-key
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_APP_URL=http://localhost:3000

MONGODB_URI=your-mongodb-connection-string
MONGODB_DB_NAME=bazardor

GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret

GITHUB_CLIENT_ID=your-github-client-id
GITHUB_CLIENT_SECRET=your-github-client-secret
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: [http://localhost:3000](http://localhost:3000)

## 🎯 সমাধানকৃত চ্যালেঞ্জসমূহ (Key Challenges Overcome)
১. **বাংলা সংখ্যার অভ্যন্তরীণ সর্টিং:** বাংলা অক্ষর/সংখ্যার স্ট্রিং হিসেবে সর্ট করলে ভুল ক্রম আসতো। তাই ডাটার আসল সাংখ্যিক মান ব্যবহার করে যথাযথ বাংলা ফরম্যাটিং বজায় রেখে সর্টিং সমাধান করেছি।  
২. **সুরক্ষিত রাউটিং ও স্মুথ রিডাইরেকশন:** সাইন ইন ছাড়া পণ্যের তথ্যে অ্যাক্সেস বন্ধ রেখে ব্যবহারকারীকে সঠিক কলব্যাক রুটে ফিরিয়ে আনার ফ্লো নিশ্চিত করেছি।  
৩. **BetterAuth ও MongoDB ক্লাউড ইন্টিগ্রেশন:** BetterAuth-এর অফিশিয়াল MongoDB অ্যাডাপ্টার দিয়ে লোকাল ও প্রোডাকশনে নির্বিঘ্ন সেশন ও প্রোফাইল আপডেট ম্যানেজ করেছি।
